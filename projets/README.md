# Projets — notes de chantier

Ce dossier contient une note Markdown par projet de meuble. Le chatbot Telegram
lit ces fichiers pour répondre à tes questions (état d'avancement, prix, délais,
prochaine étape…).

## Convention

- Un fichier par projet : `AAAA-MM-nom-client.md`
- Reprends la structure de `_template.md` (statut, étapes, budget…)
- Le champ **Statut** pilote les réponses du type « quels projets sont en cours ? ».

Statuts possibles : `Prospect`, `Devis envoyé`, `Validé`, `En fabrication`,
`Installation planifiée`, `Livré`, `En attente client`, `Suspendu`.
